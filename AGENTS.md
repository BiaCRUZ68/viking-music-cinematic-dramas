# AGENTS.md

This is a **creative production playbook**, not an executable video-generation application. Start with `PLAYBOOK.md` and `SYSTEM_PROMPT.md`.

Creative specification:
- Original Viking-inspired music-led cinematic drama.
- 16:9, 4–5 minutes by default; 9:16 only when requested.
- Original adult character designs; use consistent character reference assets and immutable descriptor blocks for every applicable shot.
- Lyrics, music prompts, synchronized scene mapping, detailed separated image/video code prompts, camera movement and ASMR.
- Distinguish historical Norse evidence from creative fantasy, and never clone existing performers' faces, voices or compositions.

Only use integrated generation or browser software when it is actually available and permitted. Do not claim exports without verifying them.
